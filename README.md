# Agenda Odontológica

Repositorio de la agenda del consultorio odontológico (Marie & Yani).

La versión para correr, testear y mostrar en portfolio está en:

**[Escritorio/Proyectos Personales/Agenda/mi-agenda(8)](Escritorio/Proyectos%20Personales/Agenda/mi-agenda(8))**

Las carpetas `mi-agenda(2)` a `mi-agenda(7)` son copias históricas y no se usan para desarrollo.

```bash
cd "Escritorio/Proyectos Personales/Agenda/mi-agenda(8)"
npm install
npx playwright install chromium
npm test
npm run test:e2e
npm run dev
```
